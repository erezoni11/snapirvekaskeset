סנפיר וקשקשת | עמוד הבית

פתיחה:
1. חלצו את קובץ ה-ZIP לתיקייה.
2. פתחו את index.html בדפדפן.

index.html - מבנה HTML מלא בעברית, RTL.
style.css - עיצוב רספונסיבי לדסקטופ ולמובייל.
script.js - אינטראקציות מקומיות: סל לדוגמה, בחירת כמות, חיתוך ומשקל, מועדפים, חיפוש, תפריט ובאנר.
assets/ - תמונות שחולצו מהמוקאפ, אייקון המותג ופונטים מקומיים. אין צורך בחיבור לאינטרנט.

זהו אב-טיפוס בצד הלקוח בלבד. המחירים, המידע, מספר הפריטים ההתחלתי וההזמנות מיועדים להמחשה. אין חיבור למלאי, סליקה, משלוחים או מערכת הזמנות אמיתית.
