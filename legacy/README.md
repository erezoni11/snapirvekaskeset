# Archived static implementation

This folder preserves the HTML/vanilla-JS implementation before the Next.js migration, including the local accessibility and checkout work. It is reference material and is not served by Next.js. Do not update the active site here.

Active routes live in `app/`, shared components in `components/`, data/admin logic in `lib/`, and assets/vendor files in `public/`. Legacy tests document the old static implementation; run the current tests from the root `tests/` directory.
